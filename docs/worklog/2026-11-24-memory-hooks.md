# 2026-11-24 — хуки памяти: обновление общей памяти и указатель агентам

Задача uyf.3 из эпика uyf (память).

## Что сделано

**Обновление общей памяти при старте** (`pullSharedMemory` в
`templates/hooks/session-start.cjs`). Путь берётся из
`<CLAUDE_CONFIG_DIR или ~/.claude>/claude-protocol.json`, ключ `shared_memory`,
который пишет bootstrap (uyf.2). Тянем, только если выбор `existing`/`new`/`local`,
папка существует, в ней есть `.git` и у ветки есть вышестоящая (`@{u}`). Запуск —
первым делом и параллельно остальным проверкам, во всех проектах, даже без
`.beads`: общая память нужна везде. Предел — 5 секунд (`PULL_TIMEOUT`),
`GIT_TERMINAL_PROMPT=0`, чтобы git не ждал пароля. Неудача — одна строка
`WARNING: shared memory not updated ...`, сессия идёт дальше.

**Указатель агентам** — новый хук `templates/hooks/memory-pointer.cjs`
(SubagentStart). Одна строка в `additionalContext`: пути к
`<главный каталог>/.memory/MEMORY.md` и `<общая память>/MEMORY.md`, к тем, что
есть. Нет ни одного — вывода нет. Пути абсолютные: `.memory` часто не в git, и в
рабочей копии своей нет. Главный каталог находится через
`git rev-parse --git-common-dir` (`mainCheckoutRoot` в `hook-utils.cjs`); вне git —
сама папка проекта. Подключён в `hooks/hooks.json` и `templates/settings.json`,
добавлен в `PLUGIN_PROVIDED_HOOKS`. bootstrap копирует все `*.cjs` и сливает
события из шаблона сам — правок в нём не понадобилось.

## Что проверять первым при поломке

- Агенты не видят строку: есть ли `SubagentStart` в установленном
  `.claude/settings.json` (npx) или в `hooks/hooks.json` (плагин); вывод хука —
  JSON `hookSpecificOutput`, обычный текст это событие не подхватывает.
- Предупреждение каждый старт: `git -C <общая память> pull --ff-only` руками —
  обычно свои незапушенные коммиты разошлись с удалёнными.
- Строка указывает не туда в рабочей копии: что отвечает
  `git rev-parse --git-common-dir` из неё.

## Что осознанно не тронуто

Находка R3 (сессия, открытая прямо в `.worktrees/bd-*`, не получает
`autoMemoryDirectory`) хуком не решалась. По бинарнику Claude Code:
`autoMemoryDirectory` из `settings.local.json` действует только при доверии к
папке, и он в списке ключей, о которых предупреждает диалог доверия («This folder
changes where automatic memory is written»). Хук, молча дописывающий такую
настройку, обходил бы это предупреждение, а подействует ли запись, сделанная во
время SessionStart, в той же сессии (память грузится при запуске), без живой
сессии не проверить. Сессии в рабочих копиях обычно одноразовые, так что «со
следующего раза» почти ничего не даёт. Агентам указатель и так даёт абсолютный
путь к `.memory` главного каталога.
